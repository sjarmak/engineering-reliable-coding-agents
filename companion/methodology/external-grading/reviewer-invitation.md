# External evidence-grading review request

I am seeking an independent check of the evidence-group instrument used in *Engineering Reliable Coding Agents*. The exercise covers 20 deterministically sampled practices and 43 scoped evidence items.

Please use the attached self-contained `review-form.html`. Work independently, do not consult the monograph's catalog or evidence ledger, and do not discuss labels with another reviewer. For each item, judge how well the cited source supports the scoped claim shown in the form. The form contains the four group definitions, source links, boundary conditions, and a rationale field.

When every item is complete, export the completed JSON response and return that file. The response will be used to report inter-rater agreement and disagreement patterns. No reader, including the author, is treated as ground truth, and the first-pass labels will not be altered post hoc to improve agreement.
